Privacy Policy

VA Trafic runs on the user's own computer. When the user connects a TikTok account, the application receives an access token through TikTok Login Kit and stores it locally on the user's device.

The token is used only to send videos chosen by the user to the user's TikTok inbox as drafts.

VA Trafic does not collect, sell or share personal data with third parties, and does not send data to any server operated by the developer.

The user can revoke access at any time from TikTok's settings and by deleting the local configuration file.
